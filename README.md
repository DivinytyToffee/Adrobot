# Adrobot

Создание кампаний Keitaro и редактор офферов. Бэкенд — FastAPI, SQLAlchemy, SQLite и Alembic. Фронтенд в `frontend/` общается с бэкендом через JSON. Демо запускается без ключа и работает без сети после установки зависимостей.

## Запуск

Откройте терминал в каталоге с `alembic.ini`. Требуется Python 3.10+. Если окружение проекта уже содержит зависимости, используйте его.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

В Linux/macOS используйте `.venv/bin/python`. Форма и редактор доступны на http://127.0.0.1:8000/, Swagger на /docs, контракт на /openapi.json. Файл .env для демо необязателен.

## Демонстрация

1. Откройте «Летние поездки». В потоке «Офферы» три активные строки с долями 34%, 33%, 33%. Добавьте «Экскурсии». В черновике четыре доли по 25%. «Отменить» возвращает исходные значения.
2. Установите «Билетам» долю 40%. Эта доля закрепляется. Остальные активные офферы делят остаток. Если их два, каждый получает 30%. Нажмите «Сохранить» и обновите страницу.
3. Снимите один из незакреплённых офферов. Проверьте долю 0% через «Показать снятые». «Вернуть» снова включает его в распределение. Последний активный оффер должен остаться в потоке.
4. На вкладке создания введите название, выберите страну по подсказке и оффер. Домен, группу и источник можно выбрать из справочников. После создания откроется редактор новой кампании.
5. В Swagger вызовите `GET /api/demo/campaigns/1/route` для DE и AU. Для DE вернётся адрес Google, для AU — ID одного из активных офферов с учётом долей. Проверка локальная и не генерирует клики.

В начальном наборе две кампании, пять офферов, по два домена, группы и источника. Seed выполняется один раз при первом запуске. База демо — `adrobot-demo.sqlite3`, изменения сохраняются после перезапуска. Для чистой демонстрации укажите новый путь SQLite через DEMO_DATABASE_URL и примените миграции. Статистика реальных переходов в демо не собирается.

## API

| Метод и путь | Назначение |
|---|---|
| GET /health | Состояние приложения и текущий режим |
| GET /api/campaign-options | countries, domains, groups, traffic_sources, offers, defaults, mode |
| GET /api/campaigns | Список доступных кампаний |
| POST /api/campaigns | Создать кампанию, геопоток и поток офферов. Заголовок Idempotency-Key — UUID операции |
| GET /api/campaign-creations/{key} | Этап создания и подтверждённые ID |
| GET /api/campaigns/{cid}/streams | Потоки, офферы, доли, закрепления и версия данных |
| POST /api/campaigns/{cid}/streams/{sid}/preview | Пересчитать черновик без записи |
| PUT /api/campaigns/{cid}/streams/{sid}/offers | Сохранить и прочитать итоговые значения |
| GET /api/demo/campaigns/{cid}/route?country_code=DE | Проверить направление по гео в демо |

Пример создания в демо: `{"name":"Demo AU","country_code":"AU","offer_id":4}`. Для повтора используйте то же тело и UUID. После тайм-аута сервис проверяет, появилась ли кампания с данным alias или соответствующий поток. Если результат нельзя однозначно подтвердить, возвращает 409.

Редактор принимает `{"revision":"<из GET>","active_ids":[1,2,3,4],"pinned":{"1":40}}`. Расчёт на сервере даст 40/20/20/20. При делении с остатком первые незакреплённые офферы в переданном порядке получают дополнительный процентный пункт. Сумма активных долей — 100%. Изменение долей на стороне трекера после открытия формы приводит к 409 при сохранении устаревшего черновика. Запускайте локальную обёртку с одним worker. Keitaro не предоставляет здесь атомарной блокировки от одновременной правки сторонним клиентом.

## Подключение Keitaro

Используйте существующий `.env` или скопируйте `.env.example` при первом запуске, установите ADROBOT_MODE=live, KEITARO_API_URL и KEITARO_API_KEY. Выполните `python -m alembic upgrade head` для live-базы из `DATABASE_URL` и перезапустите приложение. В live можно указать DEFAULT_DOMAIN_ID, DEFAULT_GROUP_ID и DEFAULT_TRAFFIC_SOURCE_ID для вызова с тремя полями. Миграция `0003` продолжает историю `0001 → 0002` и добавляет таблицы для демоданных и закреплений. Для автономной работы явно выберите demo. Реальный ключ хранится только на сервере.

## Проверка

```powershell
python -m unittest discover -s tests
```

Тесты запускают ASGI-приложение с временной SQLite и локальным транспортом. Проверяют создание, повтор по ключу, две географические ветки, черновик, сохранение, конфликт версий и восстановление оффера после перезапуска.
